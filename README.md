# Agentic Commerce AI

An AI-powered agentic commerce platform for the Razorpay AI Buildathon 2026.

## Track

AI Growth & Agentic Commerce

## Project Status

🚧 Under Development

## Overview

Agentic Commerce AI connects an AI Growth Agent for merchants with an
AI Buyer for customers.

The system aims to demonstrate how AI agents can help merchants grow
sales while allowing customers to discover and purchase products using
natural language.

## Initial Demo

The initial demo will use a fictional sports/running merchant.

A customer will be able to describe what they want in natural language,
discover suitable products, receive recommendations and offers, build
a cart, and complete a Razorpay test-mode payment.
